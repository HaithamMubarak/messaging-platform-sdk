Kept on this device only. We never store your channels on our servers — if you lose them, ask someone in the room to share the link again.

Being straight about what that is worth: this is custody, not incapability. Your channels sit in this browser’s local storage, and every app on this site runs on the same origin, so any of them could read them. We ask them not to, and the platform API never hands an app a channel password. That is a rule we keep, not a wall that would stop us.

Backup

Your saved channels live in this browser. Export a copy to move them to another device. The file is encrypted with a key held by your account, so you must be signed in as yourself to open it — a copy that leaks is ciphertext to whoever finds it.

Destroy the backup key

If a backup file of yours has ended up somewhere it should not be, destroying the key is what makes it unreadable — it is the only remedy, and it cannot be undone.

Google Drive

Keep the same encrypted file in your own Google Drive, so a new device can pick it up after you sign in. Google stores it in a hidden folder for this app and only ever sees the encrypted bytes — the key that opens it stays with your account here.
