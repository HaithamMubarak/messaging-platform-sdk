      How it works

      A knock carries nothing: not who rang, not why. The push service learns that something happened and never what. Who rang is saved to this room's storage, and the page reads it when you open it.

      "A knock was sent" is all the page can honestly say. Whether it arrives is up to the browser, the phone and the person. On an iPhone it only works from a page added to the Home Screen.

      Names in the ring list are the names people joined with. The source is doorbell.js.
