📲 Install as Progressive Web App (PWA)

✨ Why Install as an App?

✅ Works Offline
Access UI even without internet
✅ Faster Loading
Instant startup from cache
✅ Desktop Icon
Launch from Start Menu/Dock
✅ Auto Updates
Always get latest features

🌐 Chrome / Edge / Brave

  1. Look for the 📲 Install button in the toolbar (top-right)
  2. OR click the ⊕ icon in the address bar
  3. Click "Install" to add to your system
  4. The app will appear in your Start Menu/Applications folder

📱 Mobile (Android / iOS)

🤖 Android (Chrome)
  1. Tap the menu button (⋮) in top-right corner
  2. Select "Add to Home Screen" or "Install app"
  3. Confirm installation
  4. Icon will appear on your home screen
🍎 iOS (Safari)
  1. Tap the Share button (□↑) at the bottom
  2. Scroll down and tap "Add to Home Screen"
  3. Tap "Add" in the top-right
  4. The app icon will appear on your home screen

⚙️ Requirements

To use terminals, you need SDK Local Service running: 
java -jar sdk-local-service.jar
💡 Note: The PWA works offline for UI, but terminal features require SLS running on localhost:8088

✅ Verify Installation

  • App opens in standalone window (no browser UI)
  • Icon appears in Start Menu / Applications / Home Screen
  • Can launch even when offline (UI only)
  • Loads instantly from cache

🗑️ Uninstall

Desktop: Right-click app in Start Menu → Uninstall
Mobile: Long-press icon → Remove from Home Screen

🚀 Local Service Setup

⬇️ Download SDK Local Service

📦 sdk-local-service.jar ⚙️ application.properties
Requires Java 11+ • Run: java -jar sdk-local-service.jar
⚙️ Customize port, database, logging in application.properties
📥 Downloads from GitHub - always latest version
📋 Requirement: SDK Local Service must be running on localhost:8088

Step 1: Start SDK Local Service

java -jar sdk-local-service.jar

Step 2: Create Terminal Sessions

  • Click CMD/Bash/PowerShell to open a local terminal
  • Click SSH to add a remote server connection
  • Saved connections appear in the left sidebar
  • Use tabs to manage multiple sessions

🔌 REST API Reference

🔗 Test API (Health Check)
Base URL: http://localhost:8088 • All endpoints require SLS running locally

Terminal Operations

POST
/terminal/create
Create a new terminal session (local or SSH)
{
      "type": "local",
      "shell": "bash"
    }
    // or for SSH:
    {
      "type": "ssh",
      "connectionId": 1
    }
POST
/terminal/{sessionId}/input
Send input to terminal
{ "data": "ls -la\n" }
POST
/terminal/{sessionId}/resize
Resize terminal window
{ "cols": 120, "rows": 40 }
GET
/terminal/sessions
Get all active sessions
DELETE
/terminal/{sessionId}
Close terminal session
WS
/terminal/stream/{sessionId}
WebSocket stream for real-time output

SSH Connection Management

GET
/terminal/ssh-connections
List all saved SSH connections
POST
/terminal/ssh-connections
Save new SSH connection
{
      "name": "production-server",
      "host": "example.com",
      "port": 22,
      "username": "admin",
      "password": "***"
    }
PUT
/terminal/ssh-connections/{id}
Update SSH connection
DELETE
/terminal/ssh-connections/{id}
Delete SSH connection
