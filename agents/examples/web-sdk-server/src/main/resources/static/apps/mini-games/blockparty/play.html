The floor is a picture, not blocks — nothing to clear before you build. Map tiles are fetched once when you arrive somewhere and kept for that place.
Every world is 161 × 161 blocks and 40 high, at whatever scale you chose.
Because the size is part of the address. The Earth is divided into worlds by fitting a fixed number of blocks across one map tile — that is how two rooms standing in the same place at the same scale end up in the same world, and how a saved build knows which patch of ground it belongs to. Widen the world and every world already pinned somewhere either goes missing or quietly covers half the ground it was built on. To see more, step out a rung; to see more detail, step in one. Each rung is its own world, and they all still exist.
