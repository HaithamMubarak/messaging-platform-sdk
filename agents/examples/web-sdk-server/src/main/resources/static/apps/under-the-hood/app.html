What just happened

    What if the host crashes?

    Passing the crown says goodbye, so the room re-elects at once. A host that crashes, loses its network or closes a laptop says nothing. The platform notices when its session expires and announces the departure: about three minutes. Then the next in line takes the crown, exactly as here.
