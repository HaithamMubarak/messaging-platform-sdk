Requirements

To use terminals, you need SDK Local Service running: 
java -jar sdk-local-service.jar
Note: The PWA works offline for UI, but terminal features require SLS running on localhost:8088

Verify Installation

  • App opens in standalone window (no browser UI)
  • Icon appears in Start Menu / Applications / Home Screen
  • Can launch even when offline (UI only)
  • Loads instantly from cache

Desktop: Right-click app in Start Menu → Uninstall
Mobile: Long-press icon → Remove from Home Screen

Important Notes

  • Security Token: Most endpoints require an X-Security-Token header (auto-managed by UI)
  • File System: Auto-creates sessions based on terminal session ID
  • WebSocket: Use binary frames for terminal output, text frames for control messages
  • Session Restore: Include sessionId in create request to restore previous session
  • Base64 Encoding: File content must be base64-encoded in write operations

About SDK Terminal

Messaging Platform

Shared Terminal

Version 1.0.0

A web-based terminal emulator with real-time collaboration features. Connect to local terminals, SSH servers, and share your sessions with others through WebRTC. Built with modern web technologies and Spring Boot microservices.

Backend Technologies

Framework: Spring Boot 2.7.14 Language: Java 11 Build Tool: Gradle 8.14 WebSocket: Spring WebSocket + STOMP Database: H2 (Embedded) SSH Client: JSch 0.1.55

Frontend Technologies

Terminal Emulator: xterm.js 5.x Code Editor: CodeMirror 5.65.x UI Framework: Vanilla JavaScript + CSS3 WebRTC: Native WebRTC API PWA: Service Worker + Manifest Icons: Shared SVG sprite (site icon set)

Key Libraries & Addons

xterm-addon-fit: Terminal auto-sizing CodeMirror modes: JavaScript, Python, Java, CSS, HTML, Markdown, Shell CodeMirror addons: Search, Match Highlighter, Scrollbar Matches, Closebrackets Lombok: Java code generation SLF4J + Logback: Logging framework

Features

  • Local terminal sessions (CMD, Bash, PowerShell)
  • SSH connection management with saved profiles
  • Real-time terminal sharing via WebRTC
  • File explorer with SFTP support
  • Integrated code editor with syntax highlighting
  • Notes management with Markdown support
  • Session persistence and restoration
  • Multi-tab interface with keyboard shortcuts
  • Progressive Web App (PWA) support
