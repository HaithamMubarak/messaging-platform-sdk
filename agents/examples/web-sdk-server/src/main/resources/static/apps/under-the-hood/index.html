Every app here has a host. This is the one that shows you.

Presence, the elected host, the shape of the relay and the messages going through it — drawn live, from the same SDK your own app is using. Open it in two tabs, then press "step aside" and watch an election happen instead of reading about one.

Open it

Why it exists

Host election, presence and relay topology are the machinery underneath every app on this site, and none of them shows any of it. You discover there was a host the moment it leaves and something quietly stops working. This page makes all of that visible, which is why it is also the page worth having open while you are debugging one of the others.

What it draws

  • The roster — who is here, who is the host, and which peers you hold a direct data channel to.
  • The topology — a star when the host relays, a mesh when peers talk to each other. Drawn rather than described, because the difference is the whole reason the modes exist.
  • The log — joins, departures, host changes, data channels opening and messages arriving.
  • Step aside — makes the host leave deliberately, so an election is something you watch rather than something you infer afterwards.

No privileged access

Everything here is read from UserConnectionBase — the roster from getConnectedUsers(), the host from the same election every app runs, the topology from the relay mode. There is no extra protocol and no debug channel. If this page can see it, so can your app, and the code that reads it is short enough to copy.
