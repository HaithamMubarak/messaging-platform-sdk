🎨 PWA Icon Generator

Generate all required PWA icon sizes from the SVG source for SDK Terminal

📝 Instructions

  1. Click "Generate All Icons" to create PNG files from the SVG
  2. Download individual icons or use "Download All" to get a ZIP file
  3. Place all generated PNG files in the icons/ folder
  4. Reload the terminal app - the PWA install prompt should now appear!

💡 Tip: If you have Node.js installed, you can also use node generate-icons.js for automated generation with the sharp library.
