One of you gives the speech. The rest of you write it.

The speaker props their phone up and reads whatever appears on it, one line at a time. Everybody else composes lines, which go privately to the editor — nothing reaches the lectern unvetted.

The room sees the line that was just delivered, and then, a beat later, the name of whoever wrote it. That beat is the second laugh, every single time.
