If you are only opening one thing and you are on your own, use the "Playable alone" filter first: several of these want a second person before anything moves.

Open Evidence Chain

Evidence Chain

The demo of attest: the note goes to channel storage, its hash goes to the platform, which orders it, signs it and welds it to the record before. Alter an entry or delete one yourself — verification re-derives the chain and checks every signature without asking the platform whether the platform is honest, then names where it broke.

Open the party games

Party games

4 decks

Four games on one spine: the host is the only broadcaster, every player-to-host message is addressed rather than shouted, and nobody sees the state they are not entitled to.
