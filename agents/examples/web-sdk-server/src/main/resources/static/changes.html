What changed

Releases of the SDK and this site, newest first. Each entry is a release tag in the public repository, so this page and the code cannot disagree.

  1. 2026-10-05

    Faster pages, a clearer Demos page, a live home page

    Fonts are now served from this site and preloaded, so pages show sooner and text no longer jumps when a font arrives.

    The Demos page shows the SDK call each demo teaches, says whether a demo works alone or wants a second person, opens its source on GitHub, and links each demo to the product built on it. Product pages link back to their open demo.

    The home page shows who else is reading it, live, through one shared channel.

    The Docs page scrolls like the rest of the site, with a sidebar that stays in reach.

    Fixed: a client that joined a room moments before its host left now reports the handover (host_lost telemetry).
